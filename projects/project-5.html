海外制造基地 IT 基础设施建设

参与泰国制造基地 IT 从 0 到 1 建设，覆盖规划、部署验收与标准化运维。

参与范围基础设施建设与运维
项目地点泰国制造基地
协作对象供应商、IT 与制造团队
01 / 背景与挑战

泰国海外制造基地新厂投产周期紧，基础设施尚不完善，建设涉及跨国团队和多供应商协作。围绕按期交付、工程质量与运维交接，参与服务器、网络及计算资源规划和设备选型。

02 / 我做了什么
  • 对接采购、到货验收、部署与联调，协调供应商、IT、制造部门及海外团队，推进基础设施交付。
  • 开展 Linux 服务器部署、基础配置、系统测试及故障处理，支撑投产后的日常运维。
  • 通过磁盘与网络压力测试、供电联动测试核验工程质量，跟进问题整改闭环，整理设备验收文档。
  • 建设 SOP、Runbook 与应急流程；参与外部审核资料准备和现场核查，开展企业 AI 培训、知识共享与技术标准推广。
03 / 技术栈
Linux 服务器 / 网络 压力测试 SOP / Runbook 验收与应急流程
