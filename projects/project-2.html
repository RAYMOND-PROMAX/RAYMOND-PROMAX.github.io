01 / 背景与挑战

海外制造基地的服务器、网络设备、GPU 平台与工业设备监控分散，可视化口径不一，故障定位困难。平台统一 IT 侧指标与日志，并通过 MES API / 事件分阶段接入 OT 状态和告警；全厂统一告警治理仍需持续建设。

02 / 我做了什么
  • 通过 Prometheus、Exporter 与 Zabbix 采集 Linux、网络、Kubernetes、GPU 及业务服务指标。
  • 结合 ELK 日志与 Grafana 可视化，统一指标视图，支持异常检测及历史数据追溯。
  • 分阶段对接 MES API / 事件，验收设备状态与告警字段，关注数据质量及监控覆盖。
  • 验证告警规则并结合历史指标、日志定位故障；以接口验收和规则验证推进 OT 集成。
03 / 技术栈
