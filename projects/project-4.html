AIOps 智能运维 Agent

结合私有化模型、RAG 与监控信息，为员工和运维工程师提供问答与诊断辅助。

工程重点Agent 编排与 RCA 辅助
应用定位智能辅助运维
操作边界高风险操作人工确认
01 / 背景与挑战

依托 GPU 算力、统一可观测性和工业知识中台，将监控信息、历史案例与 Runbook 融入运维诊断。平台辅助分析与决策，高风险操作需人工确认，不作为完全无人值守的自动化运维系统。

02 / 我做了什么
  • 以 Dify 与 LangGraph Agent 作为应用入口和编排层，调用私有化 Qwen 系列模型，组织意图识别、任务规划、工具调用与状态管理。
  • 通过 RAG 检索、Rerank 和上下文构建调用工业知识，结合监控信息、历史案例与 Runbook 辅助 RCA 分析。
  • 管理短期会话状态、历史摘要和长期知识检索；将上下文管理与工具调用异常处理纳入诊断工作流。
  • 围绕鉴权、会话隔离及敏感数据控制设置安全边界，高风险操作保留人工确认环节。
